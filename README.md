# 🔬 Scientific Calculator – UWL Agile/DevOps Project

This is a modern scientific calculator web application developed as part of our Agile and DevOps coursework at the University of West London. It includes a clean UI, basic and advanced operations, calculation history, and responsive design. The project was collaboratively developed by a team of four using Agile methodologies and GitHub for version control.

---

## 🚀 Features

- Basic arithmetic operations: `+`, `-`, `*`, `/`
- Advanced functions: `sin`, `cos`, `tan`, `log`, `sqrt`, `pi`, `e`
- Parentheses and exponentiation support
- Evaluation using `math.js`
- Calculation history (stored in browser `localStorage`)
- Fully responsive layout using **Material UI**
- Mobile-friendly design

## 🧪 Tech Stack

- **Framework**: Next.js (React + TypeScript)
- **Styling**: Material UI (MUI)
- **Math Engine**: [math.js](https://mathjs.org/)
- **State Management**: React Hooks (`useState`, `useEffect`)
- **Persistence**: Browser `localStorage`
- **Version Control**: Git + GitHub
